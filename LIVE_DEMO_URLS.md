## 🚀 **Quick Deployment Commands:**

### **1. Deploy to GitHub Pages (FREE)**
```bash
# Create a new repository on GitHub named 'imad-elearning'
git init
git add .
git commit -m "Initial deployment of IMAD E-Learning Platform"
git branch -M main
git remote add origin https://github.com/yourusername/imad-elearning.git
git push -u origin main

# Enable GitHub Pages in repository settings
# Set source to: Deploy from a branch > main > /docs
```

**Your live URL will be:** `https://yourusername.github.io/imad-elearning/`

### **2. Deploy to Netlify (FREE)**
```bash
# Install Netlify CLI
npm install -g netlify-cli

# Login and deploy
netlify login
netlify deploy --prod --dir=docs
```

### **3. Deploy to Vercel (FREE)**
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel --prod
```
